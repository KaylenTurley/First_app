# Project layout

This is a single-file web app. Keep `AGENTS.md`, `spec.md`, `prompts.md`, and `index.html` at the project root; GitHub Pages requires `index.html` there.

Use the numbered folders for all other project files:

- `00_planning/` for notes and sketches.
- `01_data/` for data files.
- `02_validation/` for hand calculations and test cases.
- `03_output/` for screenshots and exported results.

Save every new file in the appropriate root location or numbered folder. Add a folder README when introducing another folder.
